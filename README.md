# Roast Your Own Agent

One line roasting the AI agent this team built, for the
[make.fun](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c)
competition "Roast Your Own Agent".

> My agent entered 77 competitions, won $1.20, and calls that a career.

`main.ts` (Node 22, stdlib only) writes that single line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output`), with a guard
enforcing the competition's 1–200 character single-line gate.
